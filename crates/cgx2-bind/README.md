# CGx2 pinned native binding preflight

`cgx2-bind check PACKAGE [--format text|json]` checks an explicit local binding package offline. It exits 0 only when every declaration, artifact hash, platform, ABI and exported symbol passes. A rejected package exits 1 with deterministic diagnostics; usage errors exit 2. The tool never loads the artifact, calls foreign code, installs packages, resolves source imports or falls back to Python.

The package's `cgx2.toml` uses `schema_version = 2` and `binding_lock = "cgx2-bind.lock.json"` alongside `name`, `entry` and `sources`. Existing version 1 scalar packages remain valid for `cgx2-package`, but have no binding lock and fail `bind check` explicitly. The lock is strict JSON with `schema_version: 1`, matching `package`, and a nonempty `bindings` array. Unknown fields and duplicate JSON keys are rejected. `render_lock` sorts bindings, symbols, effects and capabilities for stable bytes.

Each binding pins `id`, `route` (`native-c` or `libtorch`), `library`, exact numeric `version` (`major.minor.patch`), relative `artifact`, 64-digit `sha256`, host `os` and `arch`, matching `abi` (`c` or `libtorch-stable`), `calling_convention: "c"`, `layout: "scalar-v1"`, and nonempty `symbols`. Every symbol declares `name`, `parameters`, `result`, `ownership`, `owner`, `release`, `error`, `effects` and `capabilities`. Types are fixed-width numbers, `opaque_handle`, and `void` result. `owned` handles require a declared release symbol with shape `void(opaque_handle)`; borrowed handles require `owner: "caller"`. `foreign` effect and `native` capability are mandatory; GPU effect and capability must agree. Unsupported types, layouts, effects, ownership and routes are rejected.

Paths cannot contain traversal or escape the canonical package root through a symlink. Files are size bounded. On Linux, exported symbols are inspected with `nm -D --defined-only`; absence or inability to inspect fails closed. This preflight validates declarations and bytes, but does not establish that a declared physical signature is safe. `cgx2-ffi-native` remains unsafe until a separately reviewed adapter proves the signature, ownership and error behavior. LibTorch remains unavailable unless a compatible local artifact is pinned; no CPython route is inferred.

The `fixtures/c-abi` package and C source are compiled into a temporary local shared library by `tests/preflight.rs`, which writes a pinned lock and checks the CLI. `fixtures/libtorch-unavailable` verifies an absent LibTorch artifact is rejected.
