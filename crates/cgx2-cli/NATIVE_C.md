# Explicit native C scalar profile (Wave 12)

The source form is `unsafe foreign native fn NAME(x: i64) -> i64 effects(Foreign) caps(native) = BINDING.SYMBOL runtime "LIBRARY@VERSION" ownership copied`. `BINDING` is an ID in the package's schema 2 `binding_lock`; `SYMBOL` is its declared export. The declaration and every caller must declare `Foreign` and `native`. There is no standalone script lookup or implicit host library search.

The sole accepted physical call shape is `int32_t symbol(int64_t input, int64_t *output)`: status zero succeeds, other statuses fail before a value is published. `output` is stack storage valid only for the call. The lock symbol uses `parameters: ["i64"]`, `result: "i64"`, `ownership: "none"`, `error: "status"`, `effects: ["foreign"]`, and `capabilities: ["native"]`; its binding uses `route: "native-c"`, `abi: "c"`, `calling_convention: "c"`, `layout: "status-i64-out-v1"`. No callback, pointer-valued source argument, tensor, GPU, or general bytes signature is included.

Use `cgx2 check PACKAGE` or `cgx2 run PACKAGE`, where `PACKAGE` is the directory containing `cgx2.toml`. This first executable profile accepts one source file without imports, and a zero-argument `main() -> i64` whose body is one integer expression or return. That expression may contain checked integer arithmetic and calls to declared fixed-shape adapters. Other source constructs receive `CGN009` at both check and run.

At check and run, the package loader validates source and manifest bytes. `cgx2 check` performs static binding preflight: it validates the confined lock and artifact, exact SHA-256, host OS/architecture, declared exports, and contract fields without loading foreign code. It cannot confirm metadata function return values. At run time, the native adapter loads each artifact through its own held file descriptor, verifies library identity, exact version and ABI version 1, then calls the fixed shape. `cgx2` replaces itself with the `cgx2-native` helper for package check/run, and that helper does not link libpython. The lock and exported symbols are assertions and byte pins; they cannot prove a library's physical C signature or behavior. A caller choosing an unreviewed or malicious artifact accepts the unsafe foreign memory risk. CGx2-owned values are copied across this profile; the adapter retains no input or output pointer. The artifact hash is checked immediately before the helper loads a held file descriptor; concurrent in-place artifact mutation remains outside this preview's guarantees.

The error surface reports source spans for declaration/call errors and suppresses a success value on foreign status failure. Native and Python source emitters reject this distinct foreign AST marker until they support its semantics.
