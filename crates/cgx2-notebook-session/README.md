# CGx2 notebook session

`NotebookSession<E>` stores a `.cgnb` document, per-code-cell `CellFacts`, statuses, captured output, and a stateful `CellExecutor`. `CellFacts` has `defines`, `reads`, and `opaque_effects` (default false). It does not parse or execute CGx2 source; the kernel supplies facts and the executor.

`run_cell(id)` executes once and captures an optional `text/plain` result, up to 65,536 UTF-8 bytes. A successful result replaces that cell's output and advances its execution revision; a silent result clears display output. A failed or oversized result commits no new display and marks the cell failed. `replace_cell(id, source, facts)` invalidates the edited cell and transitive readers of its old and new definitions. `rerun_cell(id)` executes only the selected cell; the kernel's `rerun_affected(id)` subsequently executes stale readers in file order. Independent cells keep their retained definitions, output, and execution revisions. An opaque effect invalidates all later code cells. A selected cell with a noncurrent prerequisite returns `PrerequisiteNotCurrent`.

New provenance uses schema 2: `source_sha256` is the source digest, while the serialized `prefix_sha256` field is a dependency digest over direct producers and their transitive sources. Schema 1 whole-prefix records remain readable. On reopen, matching output is `Cached`, changed source or dependencies are `Stale`, and no saved record restores live executor state. `restart_and_run_all()` resets the executor and runs code cells in file order. The pure scalar kernel permits no external file, network, host-command, or arbitrary side effects.
