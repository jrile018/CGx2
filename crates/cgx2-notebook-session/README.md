# CGx2 notebook session

`cgx2-notebook-session` holds a `cgx2_notebook_format::Notebook`, per-cell dependency facts, visible statuses, output provenance, and a stateful `CellExecutor`. It does not parse or execute `.cg` source. Construct `NotebookSession<E>` with one `CellFacts` entry per code cell, keyed by stable ID. Facts contain `defines`, `reads`, and `opaque_effects` (default `false`). Invalid or duplicate IDs and inconsistent facts are rejected.

`run_cell(id)` calls `execute_cell(id, source)` once on the existing executor. A successful execution replaces that cell's `text/plain` output or clears it for a silent result, advances output and execution ordinals, and marks dependent readers stale. `rerun_cell(id)` invalidates definitions from the selected cell and every later code cell, then executes only the selected cell. `replace_cell` also invalidates that suffix, marks edited and later cached outputs stale, and uses old and new dependency facts to identify transitive readers. The suffix rule is conservative: a later definition is not reused if its file-order prefix changed. A selected cell whose static read depends on an earlier cell that is not current returns `PrerequisiteNotCurrent` and needs that cell rerun or a restart. Opaque affected cells stale all later code cells.

The pure-scalar executor commits no definitions from a failed execution. Its previous output remains visible with `Failed` status and failed-attempt provenance, never current. Saved output starts `Cached` when provenance matches or `Stale` when source or prefix hashes differ; reopening never restores live executor state. `restart_and_run_all()` resets the executor, marks old outputs noncurrent, and runs every code cell in file order. The kernel additionally clears old code outputs for a clean restart.

The `CellExecutor` trait has `execute_cell` and `invalidate_cells` hooks. Stateless adapters can implement only `execute` and `reset`; the pure-scalar kernel uses cell IDs to retain values. This crate imposes no source or value limits itself; the kernel caps code cells at 128, source at 64 KiB, and cumulative evaluation scripts and retained state at 1 MiB. Side-effecting, mutable, foreign, and memory execution remain outside the pure-scalar kernel.
