The valid two-worker profile gave conservative sequential interval
`[407646, 539548]` ns and parallel interval `[459947, 1008342]` ns. `Auto`
selected sequential CPU (`NoMeasuredBenefit`). The four-worker holdout spread
exceeded the 2× noise limit, so no profile was saved and `Auto` would fall back
to sequential. A smaller 65,536-element, four-worker run also failed the noise
gate. These observed ranges show variability in this short local run; they are
not confidence intervals or a general speedup estimate. Raw CSV and machine
profiles were kept outside the repository.

Reproduce with:

```sh
RUSTUP_TOOLCHAIN=1.98.1 cargo run -p cgx2-execution-policy --release --offline --bin calibrate_zip -- \
  1048576 2 /tmp/zip-samples.csv /tmp/zip-profile.txt
```
