# Bounded source/native memory range loops

**Goal.** Execute repeated scoped memory work through the existing `for i in range(start, end)` syntax, with a checked ownership invariant and identical interpreter/native resource and failure semantics.

**Exclusive ownership.** `crates/cgx2-ownership/**`, `crates/cgx2-sema/**`, `crates/cgx2-cli/**`, `crates/cgx2-emit-rust/**`, `crates/cgx2c/**`, `crates/cgx2-runtime/**`, `crates/cgx2-memory-conformance/**`. No syntax/package/notebook/Python emitter/verifier/effect-index/security/foreign/binding/bench/root Cargo/shared-doc edits. Preserve existing public scalar/record/notebook-facing APIs. Reuse `StmtKind::For` and existing range/conditional syntax; do not invent syntax or general iterator support.

## Bounded source contract

1. Admit `for i in range(start, end)` in memory scripts and existing acyclic local `Unit` memory functions, including nested loops, conditionals and `no_gc`. Require exactly two positional i64 endpoints; each is an in-range signed literal, declared i64 parameter or enclosing loop index. Reject arithmetic/calls/foreign/memory effects in endpoints, Bool endpoints, alternate iterators, step arguments, breaks/returns and index mutation. Evaluate endpoints once, left to right, before iteration. Use the existing ascending half-open signed range semantics: start >= end executes zero iterations. Avoid subtracting endpoints in i64 or overflow at MIN/MAX.
2. Each loop index is an immutable scoped i64 available in the existing scalar-size/call arguments and exact comparison guards. Its scope ends after the loop. Reject collisions with parameters, enclosing indices and memory bindings; sibling loops may reuse a source index name. Do not add Bool memory parameters, general scalar declarations or arbitrary outer shadowing.
3. A loop body may use existing outer handles/regions without changing their ownership state; explicitly collect outside no_gc; call existing isolated local memory functions; create owned/managed byte temporaries, move/promote/copy those local temporaries, and use borrow tokens ended before the iteration ends. As in Wave 26, every local byte value must be explicitly dropped or transferred to another local value that is dropped, and every local borrow ended on all successful paths. No loop-local region/object/reference-slot declarations, graph mutation, escaping values/tokens, outer move/drop/promote/close, or general mutation is admitted. Local function calls retain their own existing isolated region scope and closure rules; only i64 values cross those call boundaries. Existing regions/graphs outside the loop keep their behavior.

## Ownership and lowering contract

4. Add a real ownership loop operation/invariant in the owned IR and checker. Check the body from the incoming abstract state, require all per-iteration locals finished, and require preexisting value ownership/availability, regions, outstanding borrows and no_gc guards to be identical at the backedge. Preserve that same incoming state for the zero-trip join. Compare semantic outer state, excluding dead scoped-local entries; do not accept a changed state merely because checking two unrolled iterations happens to pass. Do not model the loop as `Op::If` or constant unrolling. Static invalid ownership or collect/no_gc violations must reject even when the range is empty or a branch inactive.
5. Both source-checking paths and all nested walkers must understand loops: memory admission, function extraction, local-call discovery, direct/transitive collection, region closure and scalar-argument scope. In particular a closure inside a possibly empty loop cannot prove a function's region is closed. Audit `without_local_calls`, `contains_collect`, `closes_region` and every walker that previously recursed only `If`/`no_gc`. Preserve recursion, effect/capability and package-memory rejection. No changes to runtime collector policy or APIs without a demonstrated bounded defect.
6. Checker, interpreter and native lowering need fresh per-iteration environments and cleanup, composed with Wave 26 per-arm scopes. Reusing syntactic temporary names in later iterations must not alias prior values or retain roots. Restore outer bindings after an iteration and after the loop; the index and local names must not escape. On failure unwind only actually created values/guards, retain first error/source span and distinguish pre-cleanup failure from final unwind. Explicit successful-path drop/end remains required; error cleanup does not replace it.

## Execution and limits

7. Use one non-configurable **100,000 entered-iteration limit per memory program invocation**, shared across nested loops and all local calls in interpreter and emitted Rust. Check before entering each iteration; zero-trip loops consume none, 100,000 iterations may execute and the next attempted entry fails at that loop's span. This is separate from the existing 1,000,000 statement-step limit; preserve existing steps, accounting and failure behavior. Do not reset the iteration count at a loop, branch or call boundary. Limit errors must use a stable diagnostic/message, preserve failure snapshots, and clean up exactly as other source errors. Do not expand a large range into source/IR or allocate a per-iteration program list.
8. no_gc bytes remain cumulative across all iterations, regions and calls; dropping/unrooting does not refund budgets. Untaken branches/empty ranges allocate or collect nothing. Manual collections occur only on executed explicit collect; auto allocation safepoints keep existing semantics. Repeated dropped manual objects can retain byte charges until explicit collect/close. Failed reserve/region/budget operations commit no new object. Match interpreter/native debug/native release reports for executed allocation/collection counters, roots, primary failure, rollback meaning and final cleanup.
9. Python memory emission, notebook pure admission and scalar-only verification remain rejecting unsupported memory. Exercise them read-only after admission changes. Add readable success/limit/failure fixtures and owned profile documentation, with no leak-freedom or whole-language proof claim.
