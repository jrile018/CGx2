# Conditional source/native memory with conservative joins

**Goal.** Connect the existing ownership IR branch checker to a bounded source memory conditional profile, with selected-path runtime/native behavior and auditable failure cleanup.

**Exclusive ownership.** `crates/cgx2-ownership/**`, `crates/cgx2-sema/**`, `crates/cgx2-cli/**`, `crates/cgx2-emit-rust/**`, `crates/cgx2c/**`, `crates/cgx2-runtime/**`, `crates/cgx2-memory-conformance/**`. No syntax/package/notebook/Python emitter/effect-index/security/verifier/foreign/binding/bench/root Cargo/shared-doc edits. Preserve frozen public scalar/record APIs consumed by the notebook lane. Use existing `StmtKind::If` and ownership `Op::If`; do not add language syntax.

## Bounded source contract

1. Admit mandatory-else statements in existing memory scripts and acyclic local `Unit` memory functions, including nested conditionals and conditionals inside `no_gc`. Guards are Boolean literals or one existing comparison over exactly two i64 literals/declared i64 parameters. Comparisons parse as internal `$cgx2_cmp_eq/ne/lt/le/gt/ge` calls: accept only that exact two-positional-operand form. Reject arithmetic operands, arbitrary/local/foreign calls, memory operations, truthiness and new Bool parameters in guards. Evaluate the guard once before the selected branch; preserve source spans and existing size/parameter error handling.
2. Both branches may operate on preexisting handles/regions with the currently supported memory intrinsics and acyclic local memory calls. Local calls keep their existing isolated function scope and explicit i64 argument restrictions. Branch-local declarations are limited to owned/managed byte temporaries and borrow tokens; they must be explicitly dropped/ended on every successful path before the join. No branch-local region creation, object/reference-slot declarations, general local scalar bindings, mutation syntax, return/break/loop or handle return is added. Reject unsupported declarations even in an inactive branch. Existing source memory duplicate/shadowing rules remain conservative; do not introduce arbitrary outer-handle shadowing.
3. Branch locals do not escape, including when both arms use the same source name. Implement explicit per-arm internal naming/scope bookkeeping in checker, interpreter and native lowering. Restore the outer binding environment at the join; branch-local roots must be unregistered and owned values released. Do not merely recurse the existing flat maps: that either aliases names or retains roots. On failure, unwind only the actually created values/guards while preserving the first error and existing report snapshots. Do not claim source-level automatic cleanup as a replacement for the explicit normal-path drop/end requirement.

## Ownership and runtime contract

4. Lower both branches to the existing ownership `Op::If` and preserve its conservative joins. A handle moved/dropped/borrowed/closed incompatibly on possible paths cannot be treated as unconditionally available after the join. Regions, outstanding borrows and no_gc guard state must have valid consistent post-branch behavior. Check both branches even for literal guards; static invalid ownership or collection under no_gc cannot hide in an inactive arm. Do not linearize both branches into one unconditional operation stream or infer expected state from runtime outcomes.
5. Update both source checking paths: `check_memory_module` and memory-function extraction/lowering (`check_memory_functions`, `without_local_calls`). Recursively discover local calls, direct/transitive collection and region closure through conditionals, retaining `in_no_gc` across nested branches/calls. Audit every walker that previously assumed flat ownership ops. Existing guard/effect/capability, recursion, function-result and package-memory rejection rules remain intact. Pure scalar/public-record programs must retain their previous behavior.
6. Interpreter and generated Rust/native debug/release execute one branch, charge only executed allocations, and keep manual collection counters unchanged absent an executed explicit collect. Nested no_gc budgets remain cumulative across both regions and calls; an untaken allocation consumes no bytes and cannot fail. Failed allocations may follow the documented automatic-collection safepoint but never commit a new object. Preserve existing region/root census, first failure, pre-cleanup/final-unwind snapshots and cleanup-error reporting. Avoid changing runtime APIs/collector policy unless a demonstrated defect requires a bounded repair.
7. Python emission must continue rejecting this memory profile through its existing recursive memory detector. Notebook pure admission must still reject memory/effects; conditional verification remains scalar-only. Exercise those consumers read-only to ensure sema admission does not accidentally make them execute unsupported memory. Add readable success/failure/no_gc fixtures and owned profile documentation.
