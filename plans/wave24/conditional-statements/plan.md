# Bounded Boolean if/else statements

**Goal.** Add useful conditional control flow to the existing scalar language while treating all consumers of the new AST variant consistently. This is one coordinated language change.

**Exclusive ownership.** `crates/cgx2-syntax/**`, `crates/cgx2-sema/**`, `crates/cgx2-cli/**`, `crates/cgx2c/**`, `crates/cgx2-emit-rust/**`, `crates/cgx2-emit-python/**`, `crates/cgx2-effect-index/**`, `crates/cgx2-security/**`, `crates/cgx2-package/**`, `crates/cgx2-verify-cli/**`, and all five `crates/cgx2-notebook-*` crates. Do not edit runtime, memory-conformance, bind, LibTorch, foreign/bridge, verify-core, bench, root Cargo files, or shared documents.

## Syntax and semantics

1. Add indentation-delimited statement syntax `if <Bool expression>:` followed by a nonempty block and a mandatory `else:` block. Nested statements are allowed. No conditional expression, `elif`, comparison/logical operators, pattern matching, or implicit coercion is added. Conditions use existing Boolean literals, parameters, fields, or supported calls; arithmetic types are not truthy. Diagnose missing/misplaced/duplicate else and malformed indentation with UTF-8 byte spans. Extend canonical formatter and parser/formatter round-trip tests.
2. Evaluate the condition exactly once; execute exactly one branch. Each branch has its own lexical scope. Branch bindings do not escape; assignments to an existing mutable outer scalar persist. An immutable binding remains immutable and shadowing is local. `if` has no expression result. A function ending in the statement satisfies a non-Unit result only if both branches definitely return; use explicit `return` in both branches. A Unit function may fall through after either branch. If only one branch definitely returns in a non-Unit function, the fallthrough path still needs a later ordinary tail expression/return. Preserve normal tail-expression semantics outside the conditional, nested early returns, source-order execution, checked arithmetic and all existing call/step/depth bounds.
3. Initially support the existing scalar and immutable local-record function profiles. Example: `fn choose(flag: Bool, left: i64, right: i64) -> i64:` with `if flag: return left` and `else: return right` on indented lines. Include record field guards and record returns where that target already supports local records. Typecheck both branches, including unreachable-by-literal branches. Do not accept source memory operations in conditionals: reject conditional memory programs with a source-located unsupported diagnostic before any execution/emission, including nested/inactive branches. Ownership-state joins are a later task.

## Consumer contract

4. Add interpreter, emitted Rust/native debug/release, and standalone/package Python parity for the supported profile. Package parity is limited to the previously supported scalar signatures: keep local acyclic package scalar imports working, while record import/export across module boundaries remains unsupported. Keep atomic output installation and first-error/source-span guarantees. Preserve the explicit isolated Python worker; a supported CLI foreign call inside an executed branch runs only there, while forbidden undeclared effects/capabilities in either branch still reject statically. Emitters retain their existing supported foreign profile and reject unsupported foreign constructs explicitly.
5. Traverse guard and both branches in effect/capability analysis and call indexes. Merge security/taint state conservatively across branches; never drop an unexecuted branch from static analysis based only on a literal guard. Keep branch-local names separate. Do not allow a wildcard match to silently skip new statements in package validation, memory checking, extraction, dependency discovery, or emitters. Audit all `StmtKind` consumers.
6. Notebook support is bounded to pure function bodies using the existing scalar/local-record profiles. Collect free value/type/function dependencies from both branches and the condition, respecting branch scopes; changing a dependency used only in an inactive branch must stale users. Preserve transactional state after failure, replay/retained-value/step/depth limits, Unicode, timeout/cancellation, save/reopen and Restart and Run All. Top-level conditional cells may remain explicitly unsupported; imported/foreign/effectful/contract-bearing notebook profiles retain their existing rejection boundaries.
7. `cgx2-verify-cli` must explicitly return unsupported/unknown for conditional contract bodies unless a sound existing encoding already handles them. Do not add solver claims or silently prove one selected branch. Update owned README profile documentation and readable `.cg`/`.cgnb` examples. Root shared design changes belong to the coordinator.

## Verification and handoff

Test true/false guards, one evaluation, untaken division-by-zero/overflow, taken failure code/span, nested branch scope/shadowing, both-return and missing-return functions, mutable outer state, records, local packages, UTF-8 spans, formatter round trips, dead-branch type/effect/capability errors, unsupported memory/proof cases, native and both emitter parity, notebook inactive-branch invalidation and failure recovery. Run relevant owned suites and the full offline workspace suite (with opted-in bridge features), fmt and owned Clippy `-D warnings`; loopback HTTP tests where permitted. Use existing targeted tests, not redundant snapshots. Report exact supported/rejected profiles, checks, files, limitations, and commit. Commit only owned files and stop for review.
