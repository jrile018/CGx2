# Same-package public nominal scalar records

**Goal.** Remove the public scalar-record signature restriction for explicit imports within an already supported acyclic local package. Preserve nominal identity and visibility across interpretation and source/native output.

**Exclusive ownership.** `crates/cgx2-syntax/**`, `crates/cgx2-sema/**`, `crates/cgx2-package/**`, `crates/cgx2-cli/**`, `crates/cgx2c/**`, `crates/cgx2-emit-rust/**`, `crates/cgx2-emit-python/**`, `crates/cgx2-effect-index/**`, `crates/cgx2-security/**`, and all five `crates/cgx2-notebook-*` crates. No verifier, runtime, memory-conformance, bind/LibTorch, foreign/bridge, bench, root Cargo, or shared docs edits.

## Contract

1. Add `pub record Name:` visibility syntax; ordinary `record Name:` stays private. Format canonically and preserve UTF-8 spans. The allowed shape is unchanged: one to eight immutable `i64`/`Bool` fields, declaration-order storage and source-order constructor argument evaluation. Do not add nested/mutable/generic/managed/foreign records or new statement/expression variants. Keep the verifier lane's scalar function/conditional AST interfaces stable.
2. After explicit `import module.path`, permit public record names in qualified type annotations and constructors such as `module.path.Point`, with normal projections from values. Existing local unqualified record names continue working. A public function may accept/return a public local record or explicitly imported public record. Reject leaking a private record through a public signature, inaccessible/missing types, missing imports, ambiguous names and malformed imports before execution/emission. Imports remain manifest-listed, acyclic and local; no package registry or dependency resolution is added.
3. Nominal type identity must include defining module plus record name, independent of import/file order, field shape, emitted symbol spelling, or aliases. `left.Point` and `right.Point` with identical fields must never unify. Carry identity consistently in signatures, checked expression types, interpreter values, constructor checks, projection and target symbol/class names. Do not equate types by short name or structural field equality. No reexport aliases or wildcard imports are added. Direct module imports suffice; transitive function calls through the existing acyclic package loader may carry a defining type only when required imports are explicit.
4. Support pass-through, field projection and construction/return across public functions, including existing conditionals and scalar range loops where currently supported. Preserve source-order evaluation, checked arithmetic, effects/capabilities, call budgets, error codes/spans and first failure. Validate record metadata and all module signatures before running any entry code. Preserve package file/hash/canonical-path checks and atomic output installation; failed validation must not overwrite previous output.
5. Interpreter and native debug/release package execution, emitted Rust, and standalone emitted Python package files must agree on successful values and supported failures. Use deterministic collision-safe symbols/classes, including modules with same basename, Unicode names, fields named `self`, and user names similar to generated helpers. Python output remains self-contained for this supported profile. Preserve local-only scripts and old scalar packages. Do not silently serialize values through dictionaries/tuples in a way that loses nominal type checks.
6. Update API/call/effect/security consumers as needed without skipping record constructor or field dependencies. This lane may extend existing imported-signature metadata additively; keep existing public scalar APIs callable and old scalar verification behavior unchanged. Root manifest/lockfile and benchmark compiler subtree pins remain coordinator-owned.
7. Notebook support stays at the existing pure scalar-import plus local-record profile in this wave. Its import admission must explicitly reject public imported-record signatures/constructors/values with cell ID and source span, before execution or replay, even though general package checking now accepts them. Keep old scalar imports, local record functions, stale dependencies, save/reopen, cancellation and transactional behavior working. Do not partially accept a record and lose its nominal identity in retained state. Add a readable two-module `.cg` package example and clear owned profile documentation.

## Verification and handoff

Test successful calls through at least two modules; same-named same-shaped records rejected across modules; private record leakage; constructor/annotation privacy; missing/direct imports; Unicode and generated-name collisions; declaration-order fields with reordered constructor arguments; wrong nominal input/result; conditional record returns; checked taken-branch errors; native debug/release and Python parity; unchanged local/scalar fixtures; notebook fail-closed admission and old import behavior. Run owned suites, combined offline all-feature workspace tests, formatting and owned Clippy `-D warnings`; HTTP tests where permitted. Report exact files, commands/results, supported/rejected profiles and limitations. Record knowledge, commit only owned paths and stop for review.
