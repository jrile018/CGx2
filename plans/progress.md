# CGx2 progress estimate after Wave 17 review

**92% of the first usable release implementation scope.** This is a judgment-based inventory estimate, not a benchmark score or passed release gate. The increase from 91% reflects the deterministic pinned LibTorch package recipe and broader source/notebook behavior. Memory correctness, real library reproducibility, trusted proof, and measured LLM value remain release decisions. The OCaml-scale long-term platform goal remains below 10%; a standard library, ecosystem, debugger, language server, mature optimizer, and broad compatibility record are missing.

| First-release area | Weight | Credit now | Evidence and largest gap |
| --- | ---: | ---: | --- |
| End-to-end safe memory | 30 | 29 | Wave 17 added an allocation-free direct-runtime root census and bounded scalar byte sizes for local memory functions. Interpreter/native final-unwind reports still count source bindings rather than consuming the census; full source, foreign, concurrency, and dynamic-tool assurance remain open. The memory release gate has not passed. |
| Core language and native toolchain | 20 | 19 | Native debug/release builds handle bounded local object graphs, checked memory function sizes, and failure snapshots. Typed object IR, broader signatures, and runtime-census parity are open. |
| Modules and code understanding | 10 | 9 | Acyclic local imports and public scalar calls check and execute in a native package. Ecosystem resolution and richer module APIs remain open. |
| Library access and source translation | 10 | 9 | A bounded unsafe `.cg` CPU float64 tensor route uses a pinned ELF closure without Python; Wave 17 added deterministic schema-2 package preparation. A normally copied package, independently reproducible real CPU pins, more tensor types, and general foreign libraries remain open. |
| Native notebook | 10 | 9 | `.cgnb` retains bounded pure user-function cells and has restart/interrupt and stale-output behavior. Effectful cells are rejected; stronger lifecycle behavior and broader Jupyter-scale execution remain open. |
| Effects, contracts, proof, security | 10 | 9 | The supported SMT encoding passed a finite small-domain audit. A live trusted Z3/CVC5 result and proof for memory, foreign calls, or the full language remain absent. |
| LLM and runtime evidence | 10 | 8 | The six-task syntax packet now has incomplete public starters, private reference answers, equal compiler tools, and six passing reference checks. There are zero genuine paired LLM trials or independent human task reviews. Scored isolation remains unsupported where cgroup controllers are not delegated. |
| **Total** | **100** | **92** | Memory correctness and multiple first-release features still gate release. |

Credit reflects integrated, tested behavior on `wave17/integration`, including coordinator benchmark and LibTorch test-fixture repairs. It is not percent of time elapsed. A mock foreign test is not a real LibTorch result, a solver transcript is not a whole-language proof, and source token counts are not LLM authoring measurements. The measured CPU selection applies to one pure map primitive, not arbitrary `.cg` code or GPU execution. Wave 18 is planned in six independent worktrees; its unreviewed work earns no credit yet.
